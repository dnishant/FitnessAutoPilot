# Product — one-day meal planning slice

## Mission

Help users reach fitness goals with minimal planning overhead.

Lifecycle: UNDERSTAND → PLAN → PREPARE → EXECUTE → OBSERVE → ADAPT

## This release

One trustworthy day:

1. User authenticates
2. Completes profile
3. Sets a goal
4. System calculates `nutrition-target-v1` (if safety allows)
5. System selects structured recipes and portions them deterministically
6. Today screen shows exact meal actions and gram quantities

## Non-goals for this slice

Weekly plans, AI selection, groceries, meal prep optimizer, workouts, wearables, notifications, recovery, analytics dashboards.
